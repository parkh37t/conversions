# 팀 배정 대시보드 (Team Allocation Dashboard)

프로젝트별 구성원 투입 현황을 관리하고 시각화하는 대시보드 애플리케이션

## 주요 기능

### 1. 메인 대시보드
- 프로젝트 개요 통계 (전체 프로젝트, 진행중 프로젝트, 투입 구성원, 평균 가동률)
- 프로젝트별 그룹 투입률 차트
- 구성원별 총 투입률 차트
- 프로젝트 목록 테이블

### 2. 프로젝트 상세 뷰
- 프로젝트 기본 정보 (이름, 설명, 상태, 기간, 예산, 클라이언트)
- 그룹별 구성원 목록 (기획그룹, 디자인그룹, 퍼블리싱그룹)
- 구성원별 역할, 투입 기간, 가동률 표시

### 3. 구성원 관리 패널
- 그룹별 구성원 통계
- 구성원 검색 및 필터링
- 구성원별 상세 정보 카드
  - 총 가동률 시각화
  - 참여 프로젝트 목록
  - 과부하 상태 표시 (가동률 > 100%)

### 4. 반응형 디자인
- **모바일 (뷰어용)**: 핵심 정보 중심의 간소화된 뷰
- **데스크톱 (관리자용)**: 전체 기능 및 상세 정보 표시
- 모바일 친화적 네비게이션 메뉴

## 기술 스택

- **React 18** - UI 라이브러리
- **TypeScript** - 타입 안전성
- **Vite** - 빌드 도구
- **Tailwind CSS** - 스타일링
- **Recharts** - 데이터 시각화
- **Lucide React** - 아이콘

## 프로젝트 구조

```
src/
├── components/          # React 컴포넌트
│   ├── Navigation.tsx          # 반응형 네비게이션
│   ├── Dashboard.tsx           # 메인 대시보드
│   ├── ProjectDetail.tsx       # 프로젝트 상세 뷰
│   ├── MemberManagement.tsx    # 구성원 관리 패널
│   └── AllocationChart.tsx     # 차트 컴포넌트

├── App.tsx             # 메인 앱 컴포넌트

```

## 데이터 모델

### Member (구성원)
- 이름, 그룹, 역할, 이메일

### Project (프로젝트)
- 이름, 설명, 상태, 기간, 예산, 클라이언트
- 구성원 목록 (역할, 투입 기간, 가동률)

### GroupType (그룹 유형)
- 기획그룹
- 디자인그룹
- 퍼블리싱그룹

## 사용 가이드

### 대시보드 사용
1. 상단 네비게이션에서 원하는 메뉴 선택
2. 프로젝트 목록에서 프로젝트 클릭 시 상세 정보 확인
3. 차트를 통해 투입률 시각적 확인

### 구성원 관리
1. 구성원 관리 메뉴 선택
2. 검색 또는 그룹 필터로 구성원 찾기
3. 구성원 카드에서 가동률 및 참여 프로젝트 확인
4. 빨간색 표시는 과부하 상태 (100% 초과)

### 반응형 기능
- **데스크톱**: 모든 컬럼 및 상세 정보 표시
- **태블릿**: 일부 컬럼 숨김, 차트 크기 조정
- **모바일**: 핵심 정보만 표시, 햄버거 메뉴
